# Agent Context Bridge 领域术语

本术语表定义项目上下文交接的统一语言。这里仅定义领域概念，具体结构与行为见相应设计文档。

## Language

**Project（项目）**：具有稳定身份的一份开发项目；不同设备上的目录可以属于同一个 Project。
_Avoid_：用本机绝对路径代表项目身份。

**Task（任务）**：一次交接所围绕的目标、约束与验收条件；同一 Project 可以有多个 Task。
_Avoid_：用分支名等同任务。

**Session（开发会话）**：一个 Agent 在特定工作环境中持续处理任务的一段工作过程。
_Avoid_：把 Session 等同某个模型。

**Harness（运行载体）**：负责启动 Agent 并为其提供工具、权限和上下文的开发运行环境。
_Avoid_：把 Harness 等同模型或项目。

**Snapshot（代码快照）**：某个时点被明确纳入交接的代码内容及其必要的 Git 状态。
_Avoid_：仅用 HEAD 代表包含未提交工作的快照。

**Project State（项目状态）**：围绕一个 Snapshot，组织项目事实、验证记录、任务信息与声明的标准化状态描述。
_Avoid_：仅用聊天摘要代表项目状态。

**Observation（观测）**：由工具在特定时间与范围内采集到的项目事实。
_Avoid_：把推测描述为观测。

**Agent Claim（Agent 声明）**：Agent 对进展、原因、决策或下一步提出的叙述；它可以关联证据，但本身不等同验证结果。
_Avoid_：将 Agent 自报的完成状态直接当作事实。

**Verification Record（验证记录）**：针对指定代码输入与环境执行一次检查所产生的结果和证据。
_Avoid_：不注明对应代码的“测试通过”。

**Handoff Package（交接包）**：将 Project State、代码恢复材料、验证证据与阅读入口封装起来的一次可传递交接。
_Avoid_：只包含待办事项的交接。

**Publication（发布）**：某个交接包在指定存储目标中可被定位和获取的持久化记录。
_Avoid_：将上传中等同已发布。

**Resume Report（恢复报告）**：接收端对一次交接的完整性、代码恢复、环境差异与可继续程度作出的本地评估。
_Avoid_：用原发送端测试结果代替接收端评估。
